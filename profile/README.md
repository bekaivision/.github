Bekai Vision is an independent computer vision and robotics engineering studio founded by [Alibek Erkabayev](https://github.com/bigalex95). We help teams turn visual data into working systems — from the first proof-of-concept to optimized models running on cloud and edge hardware.

### 🔍 What we do

| | |
|---|---|
| **Detection & tracking** | Object detection, segmentation and multi-object tracking for real-world video |
| **Visual inspection** | Defect detection and dimensional validation for industrial quality control |
| **3D vision** | Depth, pose estimation, SLAM / VIO, feature matching, 3D reconstruction |
| **Robot perception** | Perception stacks for robots and autonomous systems (ROS) |
| **Edge deployment** | TensorRT, ONNX and quantization for NVIDIA Jetson and real-time GPU pipelines |
| **AR & web vision** | C++ → WebAssembly, WebGL / OpenGL ES, vision in the browser |
| **R&D consulting** | From paper to prototype: method selection, datasets, evaluation |

### ⚙️ How we work

1. **Define** — a measurable goal and the metric that proves it
2. **Prototype** — fast experiments on your real data
3. **Optimize** — latency, accuracy and cost tuned for your target hardware
4. **Deliver** — maintainable code, documentation and a system that runs outside the notebook

### 🧰 Stack

`Python` `C++` `PyTorch` `OpenCV` `TensorRT` `ONNX` `ROS` `Jetson` `WebAssembly` `Docker` `FastAPI`
